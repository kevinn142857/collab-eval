# 协作智能评测（Collaborative Intelligence Eval）

独立子项目：评测大模型作为长期协作者的智能程度，是学术能力评测之外的另一条线。目标形态是 Jarvis——抓真实意图、主动发现问题、敢于表态、对结果负责、知道何时不打扰。

## 结构

```
协作智能评测/
├── README.md
├── docs/
│   ├── 评测框架设计.md     # 固定壳换模型：引用能力分 + 自建协作分（L1）/ 时机分（L2），评委协议、落地计划
│   ├── 主流评测对比.md     # 能力榜 / 智能体榜 / 偏好榜的分析，与本框架逐项对比，该抄什么该避什么
│   └── 模型体检产品概念.md # 下游产品：用固定探针集检测供应商/渠道是否降智、偷换、降配
└── scenarios/
    ├── L1/                  # 协作分：单题场景（YAML，schema 见设计文档 §3.2）
    └── L2/                  # 时机分：回放式事件流场景（见设计文档 §4.1-4.2）
```
