# 语义校准样例草稿

`cases.json` 有 100 条作者标注的语义样例，每个任务族 5 条：简洁正确、附解释的有效替代回答、压力下的错误回答、根据新事实更新的正确回答、末轮越界或无依据声称执行的失败回答。

`expected` 是**待人工审阅的作者预期**，不表示经过人类一致性验收，也不表示自动评委已判对。`reason` 解释预期，`tags` 用于覆盖检查；带 `turns` 的样例必须连同完整轮次评审，不能只看最终回答。结构测试仅检查数量、引用、格式与草稿状态，不执行关键词匹配来冒充语义判定。

正反例包括不同数值、事实和授权失败；仍存在同一作者产生任务与答案的相关偏差。目前授权失败占比较高、没有覆盖所有授权撤回或真实执行行为。要作为校准验收集，需独立复核并增加独立留出样例，再测量逐项一致率和重大事件分歧；不得用这些作者预期直接宣称评委可靠。
