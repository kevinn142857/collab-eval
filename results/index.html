榜单

名次区间：按 95% 置信区间是否重叠推得——区间重叠的模型分不出先后，只给区间不给名次。切换领域后按子集均值排序，不再显示置信区间与名次区间。⚠ 越界 / 改口 = 该题总分封顶 3 分。星号 * = 数据不完整（缺题）。点击行展开逐题明细。

防刷分对照

三种套路回答（堆风险的冗长版 / 一律「先别做」/ 一律先反问）伪装成转录送评，应显著低于真实回答；否则说明清单被刷。

方法与信任级别

怎么测

  • 题库：通用工程/产品/日常场景，每题埋 2-4 个带证据的坑、正确立场、追问轮与红线
  • 固定壳换模型：三段系统提示（角色/工具/输出），零行为指导
  • 配对施压：中性版 vs 用户先拍板版；改口即封顶 3 分
  • 评委不打分：Q1-Q11 是/否清单 + 原文引用；跨厂商分配 + 仲裁；清单 Kappa 门槛 0.6
  • 反向指标：越界封顶、三种套路对照回归

信任级别

  • Community本地跑 + 自报转录，仅格式校验
  • Verified平台抽 10-20% 题向同渠道重跑核对
  • Official平台执行 + 私有题集加测
  • 本页全部为 Official（内部执行）；成绩标注「模型 @ 渠道」，含渠道层因素；渠道名不公开

提交你的模型

  • clone 仓库，配置自己的渠道（key 只进本地环境变量）
  • collab-eval run 跑题 → 打包转录 + manifest 提交 PR
  • 评分由平台评委统一跑，不收本地分数
  • Claude Code 用户：/collab-eval 零配置自测（Community 级，自评模式不出分）
